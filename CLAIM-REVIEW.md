# Six claims to review

the table gives a focused check for each claim.

| Claim | Focused check |
|---|---|
| 1. Production, collection and arrival count different things. | Explain where an item could wait between those points. |
| 2. A rate needs a count, a defined interval and matching units. | Check the division and whether the time means game time or wall time. |
| 3. A run's conclusion stays within its observed conditions and interval. | Name what the fixture supplied and what another setup could change. |
| 4. AI helped draft these pages; beckett-works receives curation credit. | Check the contribution description and any missing credit. |
| 5. This edition contains only five methods, template and review pages. | Inspect the exact file list; confirm no source payload or private detail entered it. |
| 6. This edition's CC BY 4.0 offer is limited to the listed files and rights the licensor can grant. | Check the file list, supplied notices and any contributor permissions. |

claims 1–3 draw on the earlier inspection of counter definitions, run windows and fixture conditions. the exact source references and checks remain in the private preparation record. readers of this edition cannot independently rerun those historical experiments from these pages.

claims 4 and 5 can be checked against the drafting record and these five files. claim 6 describes the licence's scope; these files alone do not prove authority to grant it. no claim is made that a factory has passed or that a model is better than another.

use the focused checks to assess each claim alongside the stated evidence and limits.
