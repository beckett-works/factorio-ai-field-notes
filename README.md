# factorio-ai-field-notes

**Methods edition · evidence cutoff: 8 October 2026, 23:58 UTC**

factorio-ai-field-notes is a small guide to recording AI-assisted Factorio experiments. the aim is to make each result understandable: what was counted, under which conditions, and what remains unknown.

this edition contains methods and one blank run record. it includes no performance ranking, factory design or blueprint. it uses evidence inspected by 8 October 2026, 23:58 UTC. later experiments and scoring changes belong to a later edition.

beckett-works is credited for curation. AI helped draft these pages. curation credit does not mean that every page or claim has been personally reviewed.
