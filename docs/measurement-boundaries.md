# Measurement boundaries

## 1. Say what was counted

production, collection and arrival answer different questions.

production counts items made. collection counts items taken at a chosen output. arrival counts items reaching a destination. items can remain in machines, on belts or in storage between those points. a production total alone does not tell us how many items reached the destination.

choose the counter that answers the question. describe where it is measured. record stock separately rather than silently treating a stock change as production.

## 2. Show the denominator

a rate needs both a count and an interval:

**rate = counted output ÷ measured time**

name the unit, such as items per game-minute. record the interval's start and end and any warm-up left out. game time measures progress inside Factorio; wall time measures how long the host took to run it. do not use one in place of the other.

arithmetic can confirm the division. it cannot confirm that the observer counted the intended items or chose the right boundary. those checks need the observation method too.

## 3. Keep the conditions attached

a run supports a statement about the design, conditions and interval actually observed. it does not by itself establish performance for all future time or every other setup.

write down the game version, research, allowed qualities, inputs and power. disclose anything the test supplied artificially: built entities, injected materials or a sink that removes output. these choices define what the result means.

if the goal applies to each cell, check each cell. a combined total can hide a weak instance. if a longer run conflicts with an earlier pass, keep both records and narrow the conclusion.

## Leave unknowns visible

separate a stored report, a calculation, a game observation and a possible explanation. “the totals agree” is narrower than “the factory is stable.” a proposed repair remains proposed until its outcome is measured.

these are reporting methods, not new factory results. this edition reports no throughput figure, model comparison or scoring rule.
